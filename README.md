# mango_drone

## 足球無人機 Web 模擬器（`simulator/`）

在瀏覽器中練習無人機足球（Drone Soccer）的 3D 模擬器。純前端、免安裝、免建置，電腦、手機、平板都能玩。

### 功能

- **3D 場地**：網籠、場地標線、雙方球門環（three.js）。
- **飛行物理**：推力、重力、空氣阻力、姿態動態，可選 **定高輔助**（放開油門即維持高度）或 **自穩 + 手動油門**。
- **碰撞**：機體間碰撞（動量守恆、摩擦）、撞網反彈、球門環與支柱碰撞；撞擊過猛會被撞落，2.5 秒後可重新起飛。
- **比賽規則**：
  - 每隊一架 **攻擊手（金色雙環）**，只有它能得分。
  - 攻擊手須 **從正面穿過對方球門環** 才算得分。
  - 得分後攻擊手須 **飛回己方半場** 才能再次得分。
  - 每局限時，多局制（預設三局兩勝），平手比總進球。
- **AI**：AI 飛手和玩家一樣只輸出搖桿量，用同一套物理飛行。角色分成攻擊手、守門、攔截、護航、封堵，難度分三級。
- **模式**：對戰 AI（3v3 / 5v5）、自由練習（可加 AI 守門員）。
- **視角**：跟隨、FPV 第一人稱、看台、俯視。
- **操控**：鍵盤、遊戲手把／USB 模擬器遙控器（Mode 1 / Mode 2）、手機觸控虛擬搖桿。
- **場地規格**：DS40（40 cm 球型機）與 DS20（20 cm），球門可放大給新手練習。

> 場地與機體尺寸以 FAI 無人機足球規格為參考，但只是近似值，可在 `simulator/src/config.js` 依實際採用的規則書調整。

### 執行

ES Module 必須透過 HTTP 載入，不能直接用 `file://` 開啟：

```bash
cd simulator
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

three.js 會從 jsDelivr CDN 載入，所以需要網路連線。也可以直接把 `simulator/` 部署到 GitHub Pages 或任何靜態網站主機。

### 操作

| 動作 | 鍵盤 | 手把（Mode 2） |
| --- | --- | --- |
| 油門／升降 | `W` / `S` | 左桿上下 |
| 偏航（旋轉） | `A` / `D` | 左桿左右 |
| 前後 | `↑` / `↓` 或 `I` / `K` | 右桿上下 |
| 左右平移 | `←` / `→` 或 `J` / `L` | 右桿左右 |
| 精細操作 | 按住 `Shift` | — |
| 切換視角 | `C` | Y |
| 切換操控的隊員 | `Tab` | X |
| 重置（練習模式） | `R` | B |
| 暫停／選單 | `Esc` / `P` | Start |

### 程式結構

```
simulator/
├── index.html        介面與 HUD
├── style.css
├── src/
│   ├── config.js     場地、機體、物理參數
│   ├── vec.js        向量工具
│   ├── drone.js      無人機動力學與飛控（自穩／定高）
│   ├── world.js      場地、球門、碰撞
│   ├── rules.js      得分判定、局數與計時
│   ├── ai.js         AI 飛手
│   ├── input.js      鍵盤／手把／觸控
│   ├── render.js     three.js 畫面與攝影機
│   ├── audio.js      音效
│   └── main.js       主迴圈
└── test/sim.test.mjs 物理與規則測試
```

物理、規則與 AI 不依賴 three.js，可以在 Node 直接測試：

```bash
cd simulator
npm test
```

物理以固定步長 120 Hz 更新，畫面依瀏覽器更新率繪製。
