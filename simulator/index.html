足球無人機模擬器

球型保護籠無人機在網籠內對戰。每隊只有一架攻擊手（金色雙環）能得分：從正面穿過對方球門環即得 1 分，得分後須飛回己方半場才能再得分。其他隊員負責攔截、衝撞與護航。

模式

設定

鍵盤

  • W/S 油門（定高模式為升降）
  • A/D 偏航（左右旋轉）
  • ↑↓ 或 IK 前後；←→ 或 JL 左右平移
  • 按住 Shift 精細操作
  • C 視角、Tab 換機、R 重置（練習）、Esc 暫停

手把 / 遙控器

  • Mode 2：左桿 油門＋偏航、右桿 俯仰＋橫滾
  • Mode 1：左桿 俯仰＋偏航、右桿 油門＋橫滾
  • Y 視角、X 換機、B 重置、Start 暫停
  • USB 模擬器遙控器通常會被當成手把

觸控

  • 畫面下方左右兩個虛擬搖桿
  • 建議使用「定高輔助」：放開油門即維持高度
  • 橫向持握手機較好操作
